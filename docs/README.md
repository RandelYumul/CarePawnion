# Project documents

This folder holds the planning and project documents for CarePawnion. They are
kept in the repository so they stay versioned with the code they describe.

| File | What it covers |
| --- | --- |
| [01-proposal.md](01-proposal.md) | The revised proposal, with the problem, the five screens, the data each screen needs, and the API functions it uses |
| [02-mockup.md](02-mockup.md) | The wireframes and high fidelity mockups for each screen on desktop and phone |
| [03-design-system.md](03-design-system.md) | The colours, type, spacing, components, and accessibility checks |
| [04-weekly-reports.md](04-weekly-reports.md) | A short report for each week, with what was done, what got stuck, the hours, and what came next |
| [05-demo-video.md](05-demo-video.md) | The link to the demo video and the plan it followed |
| [06-security-and-privacy.md](06-security-and-privacy.md) | The privacy and security checks made before the repository was made public |
| [07-security-checklist.md](07-security-checklist.md) | The full security checklist, with evidence for each row |
| [../AI-USAGE.md](../AI-USAGE.md) | How AI was used to build the app, where it got things wrong, and who wrote what |

Images used by these documents are in `assets/`, including the wireframes, the
mockups, and the screenshot shown in the main README.

The weekly reports were written during each week, so they show the problems and
decisions as they happened.
